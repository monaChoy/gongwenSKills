# 国企通用文件写作（领导式方法论）

写国企场景文件时使用：工作汇报、项目信息/进展汇报、专项汇报与总结、报告、请示、情况说明、通知，以及配套的 PPT 提纲与发言稿。方法论提炼自领导修订真实汇报的实践；本技能只保留抽象后的流程与句式，不含具体项目信息。

## 通用工作流

### 1. 识别任务

先确定五件事：**文种、收文对象、目的（读者读完要知道什么、决定什么）、项目阶段（前期/实施/验收/运行）、输出载体与篇幅**（PPT、发言稿、文字报告、一页简报）。

- 已有材料能判断的直接推进；只有影响结构的关键信息缺失才询问。
- 用户指定的模板、格式与篇幅优先于本技能的默认结构。

完成判据：五项均有答案或明确默认；据此进入第 3 步选定结构模板。

### 2. 整理材料

- 事实以用户提供的资料为准；不编造文号、数字、案例与项目事实。
- 把材料分成四堆：已核实事实、计划/目标、建议/诉求、待核实。状态与时间必须有依据——规划、采购、实施、验收不混写。
- 缺口处理：影响成文的关键缺口标【待确认】或向用户索取；与本文无关的缺口不追。

完成判据：材料分堆完毕；关键缺口已标注或已索取。

### 3. 选结构

按文种从 [references/templates.md](references/templates.md) 选模板。

- 模板是默认结构，不是必选页序：按「读者需要知道什么、决定什么」增删，不为凑模板增添材料。
- 删节边界：与本次目的无关或可选且无素材的章节直接删；必要内容（如验收状态、关键风险、经费依据、需决策事项）即使资料暂缺也必须保留，标【待确认】，必要时询问用户——不能只因缺素材而删除。
- 上级文件只在相关且有据时引用（核查直接相关性、适用性、有效状态）；不为「高度」硬加政策。

完成判据：选定一个模板并列出裁剪点（删改了哪节、为什么；保留了哪些待确认缺口）。

### 4. 起草

国企语体：正式、准确、克制；层次清楚；数字口径一致；职责与行动明确。

- 结论先行：核心结论与需决策事项前置。
- 与本次文件有关的问题、影响、依赖、责任和时限如实写明；表达客观克制，不作无依据的指责。我方措施与他方待办可以同时出现。
- 口吻看对象：对业主/上级单位，必要性依据已核实事实、业务需求及适用政策阐明；避免无依据或情绪化评价，不回避与本文有关的客观问题。需要对方行动的写成「需协调事项」并明确责任与时限；仅需表态的场合用「我方主动跟进」行动句。

完成判据：初稿覆盖裁剪后的各节；每节落回第 2 步的材料堆，无来源的断言已标【待确认】。

### 5. 交付核查

- 事实状态：规划/采购/实施/验收、估算/概算/报价/批复预算等口径与实际一致；不预设无依据的沟通历史或范围变化。
- 数据口径全文一致；责任、时限、需决策事项明确。
- 借用过模板或他项目材料的：全文检索其专有实体（地名、设施名、规模数字），无未经说明而迁入本项目的实体与数字；有来源、明确标注的对标案例允许保留。

完成判据：三类核查逐项通过。

## 红线

1. **事实可核实**：文号、印发时间、数字、案例以用户提供的材料为准；不编造；必要缺口标【待确认】。
2. **政策有据且相关才引用**：核查直接相关性、适用性与有效状态；不为「高度」硬加政策。
3. **问题如实写**：与本次文件有关的问题、影响、依赖、责任和时限不省略、不弱化；表达客观克制，不作无依据的指责。
4. **借模板必清洗**：交付前全文检索模板与他项目的专有实体；无来源、未标注的他项目实体与数字不得迁入。
5. **用户模板优先**：用户提供的格式模板、指定结构与篇幅，优先于本技能的一切默认值。

## 反模式

每条给「典型表现 → 正确写法」。

1. 围着素材自下而上组织（逐项罗列设备、工作或事项）→ 立意先行：先答「读者要知道什么、决定什么」，素材服务结构。
2. 为凑模板增添材料（无关的政策、架构、案例）→ 模板按需裁剪：无关或可选的节可删，必要内容缺资料时保留为【待确认】。
3. 只借术语不借结构（堆时髦名词，背后没有分层逻辑）→ 方案类文件连骨架一起借；颗粒度以读者能理解、评估、决策为终点，简单内容不必强拆下一层。
4. 目标与成效写成口号（押韵对仗、无转变、无证据）→ 方案/目标表达场景用转变对句式 + 可核实依据；通知、简报等直接写清事项与要求即可。
5. 协调事项写成单方面表态（只剩「我方主动对接」，读者不知谁该在何时做什么）→ 依赖、责任、时限写明，我方措施与他方待办并列。
