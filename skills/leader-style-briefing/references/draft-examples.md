# 虚构成稿示例

以下例稿均为虚构，使用通用占位符 `〔〕`。用于示范常用文种的完整成稿形态与口径控制，**不可当作真实发文**，也不代表已对模型效果做过对比测评。与 [虚构审稿案例](review-examples.md) 分工：本文件侧重成稿示范，审稿案例侧重问题定位与事实保护。

---

## 例稿一：请示

| 项 | 内容 |
| --- | --- |
| 性质 | 虚构示例 |
| 用途 | 示范一文一事请示的结构与可批复表述 |
| 文种 | 请示 |
| 使用限制 | 不可当作真实发文；数字与节点均为占位 |

**关于〔项目名〕〔事项〕经费安排的请示**

〔上级单位〕：

为推进〔项目名〕〔阶段〕工作，拟申请安排相关经费。现将有关事项请示如下。

一、拟请示事项

拟申请安排〔项目名〕〔事项〕经费约〔金额〕万元（估算口径），专项用于〔用途范围〕。请予审定。

二、理由与依据

1. 〔依据文件或会议〕明确要求〔单位〕在〔时限〕前完成〔任务要点〕。
2. 现有资料《〔方案或清单名称〕》列示拟配置〔设备或服务〕〔N〕项；尚未取得采购合同及验收记录，实际采购与实施状态【待确认】。
3. 现有《〔供应商〕报价单》总价约〔金额〕万元；预算批复情况【待确认】。本请示金额按估算口径表述，不作为已批复预算。

三、方案、资源及影响

1. 拟实施内容：按《〔方案名称〕》推进〔主要工作〕，覆盖范围限于〔范围说明〕。
2. 经费构成（估算）：〔类别甲〕约〔金额甲〕万元、〔类别乙〕约〔金额乙〕万元；各项费用拟不超过〔上限〕万元。明细以正式测算或批复为准。
3. 若不及时安排：〔阶段节点〕可能延后，影响〔下游工作〕推进；具体影响范围【待确认】。

四、拟提请决定的内容

1. 是否同意按估算口径安排〔项目名〕〔事项〕经费约〔金额〕万元。
2. 是否明确经费渠道为〔渠道表述〕，并明确后续以正式批复金额为准。
3. 其他需明确事项【待确认】。

妥否，请批示。

〔请示单位〕
〔日期〕

## 例稿二：进展汇报

| 项 | 内容 |
| --- | --- |
| 性质 | 虚构示例 |
| 用途 | 示范进展汇报的状态、偏差、风险与协调事项 |
| 文种 | 进展汇报 |
| 使用限制 | 不可当作真实发文；进度与数字均为占位 |

**〔项目名〕〔统计期〕进展情况汇报**

一、核心结论

截至〔统计截止日〕，〔项目名〕处于〔阶段名称〕。本期完成〔关键事项〕〔N〕项；〔节点名称〕较计划延后约〔天数〕天，主要原因是〔原因摘要〕。需〔协作方〕于〔节点〕前提供〔资料或条件〕，否则影响〔下一阶段〕定稿。

二、项目概况与当前状态

1. 建设范围：〔范围说明〕；本期统计口径为〔口径说明〕。
2. 当前状态：方案编制〔状态〕；采购〔状态〕；现场实施〔状态〕。验收相关结论尚未形成，不作“已验收”表述。
3. 经费口径：现有资料为〔报价/估算/概算〕约〔金额〕万元；批复预算【待确认】。

三、计划与实际

| 事项 | 计划节点 | 实际进展 | 偏差及原因 |
| --- | --- | --- | --- |
| 〔事项甲〕 | 〔日期甲〕 | 已完成〔简述〕 | 无 |
| 〔事项乙〕 | 〔日期乙〕 | 完成约〔比例〕 | 因〔原因〕延后约〔天数〕天 |

四、问题风险及措施

1. 〔风险一〕：〔影响说明〕。我方已〔已采取措施〕；拟于〔节点〕前〔拟采取措施〕。
2. 〔风险二〕：基础资料尚未齐套，影响方案定稿。我方已整理资料清单；需对方行动见下文。

五、下一步安排

1. 〔日期〕前完成〔任务〕。
2. 〔日期〕前形成〔成果物〕送审稿（以资料齐套为前提）。

六、需协调/决策事项

1. 请〔协作方〕于〔节点〕前提供〔基础资料清单要点〕。
2. 请明确〔决策事项〕是否按〔方案要点〕推进；相关责任分工【待确认〕。

〔汇报单位〕
〔日期〕

## 例稿三：通知

| 项 | 内容 |
| --- | --- |
| 性质 | 虚构示例 |
| 用途 | 示范可执行通知的对象、时限、渠道与反馈要求 |
| 文种 | 通知 |
| 使用限制 | 不可当作真实发文；对象与节点均为占位 |

**关于报送〔事项〕清单的通知**

〔各部门/各单位〕：

为做好〔工作名称〕相关资料汇总，现就报送〔事项〕清单有关要求通知如下。

一、报送对象与范围

请〔相关部门〕按附件模板填报本部门〔事项〕清单，统计期为〔起始日〕至〔截止日〕，范围限于〔范围说明〕。

二、具体要求

1. 按附件模板逐项填写，不得漏填〔必填字段〕；数量须注明单位。
2. 口径说明：〔口径要点〕；无法确认的字段标注“待核实”，不得以估计值冒充已核实数据。
3. 如无相关事项，亦须书面回复“无”。

三、责任、时限及办理方式

1. 责任：各部门明确一名联系人，于〔联系人反馈节点〕前将姓名及联系方式告知〔收集部门〕。
2. 时限：请于〔报送节点〕17:00 前完成报送。
3. 渠道：通过〔报送系统或邮箱〕提交至〔收集部门〕；文件命名为“〔单位简称〕-〔事项〕清单-〔日期〕”。
4. 逾期未报的，由〔收集部门〕汇总后通报【待确认是否需要】。

附件：1. 〔事项〕清单模板  
2. 填报说明

〔发文单位〕
〔日期〕

## 例稿四：党建短材料

| 项 | 内容 |
| --- | --- |
| 性质 | 虚构示例 |
| 用途 | 示范学习贯彻类党建短文的「依据—动作—成效」闭环 |
| 文种 | 党建短材料 |
| 使用限制 | 不可当作真实发文；人次与成效表述均为占位；避免作空泛政治套话范本 |

**〔单位〕党支部开展〔专题名称〕学习研讨情况交流**

一、背景依据

根据〔上级党组织〕关于深入开展〔专题名称〕的部署，以及〔适用文件全称〕（文号【待确认】）有关要求，〔单位〕党支部把学习贯彻与本单位〔业务领域〕重点工作结合起来，明确以“学懂要求、找准差距、推动整改”为主线，避免学习与业务“两张皮”。

本期交流材料统计期为〔起止日期〕。依据文件适用范围、是否另有补充通知【待确认】；本稿仅反映支部已组织并有记录的学习研讨情况，不代替上级考核结论。

二、落实动作

1. 学习安排。支部于〔起止日期〕组织集中学习〔N〕次，每次〔时长〕左右，参加对象为〔党员/入党积极分子等范围说明〕；指定〔责任人〕负责通知、签到与学习记录。自学篇目包括〔篇目或要点一〕、〔篇目或要点二〕，要求结合岗位写出不少于〔字数〕字的要点笔记。实际到学人数、请假及补学完成情况【待确认】，本稿不以“应到尽到”代替未核验数据。

2. 研讨交流。围绕“〔研讨题目一〕”“〔研讨题目二〕”开展〔小组讨论/案例交流〕〔N〕场，引导对照〔制度或流程名称〕查找短板。研讨形成问题清单〔N〕条，按“问题描述—责任主体—拟办措施—时限”四要素登记；其中〔问题类型甲〕〔N〕条、〔问题类型乙〕〔N〕条。清单是否已向〔上级党组织〕备案【待确认】。

3. 结合业务抓整改。针对清单中影响〔业务环节〕的问题，会同〔业务部门〕梳理〔制度或流程〕修订建议〔N〕条：已纳入〔近期工作安排〕并明确牵头人的〔N〕条；仍在论证、暂不纳入本期安排的〔N〕条，文中单独注明，不作“已全部整改”表述。对涉及经费、编制或对外承诺的事项，一律转由相应请示或方案办理，不在党建短材料中直接拍板。

4. 资料与留痕。集中学习记录、签到表、问题清单及修订建议底稿由〔责任人〕归档至〔存放位置或台账名称〕；对外报送口径与本稿不一致时，以经审定的报送稿为准【待确认】。

三、成效与下一步

1. 阶段成效（有据部分）。已完成既定集中学习与问题梳理，形成《〔材料名称〕》送审稿；在〔具体工作〕方面，已明确〔N〕项岗位职责边界，并将〔N〕条可立即执行的操作规范纳入〔内部通知或操作指引〕试行。覆盖率、满意度、表彰等评价性结论【待确认】，本稿不使用“全员覆盖”“显著提升”“圆满完成”等缺少核验依据的表述。

2. 仍存在的差距。问题清单中〔N〕条依赖〔外部条件或上级政策〕，本期仅完成梳理；〔制度修订〕中〔N〕条尚待〔决策会议〕审议，生效时间【待确认〕。

3. 下一步安排。拟于〔节点甲〕前完成问题清单销号复核，由〔责任人〕对照台账销号并说明未销号原因；拟于〔节点乙〕前将适用的修订建议提交〔决策会议〕审议；需要上级明确政策适用或资源安排的，另行请示，不在本稿作出完成时限或资源承诺。

〔单位〕党支部
〔日期〕
