# 像不像核对表（自写）

交付前快速核对。用于国企/央企材料「像成稿、能用」，不是风格参数引擎，不替代事实核验。

## 结构

- [ ] 文种与读者匹配；用户指定模板时栏目与顺序已遵守
- [ ] 标题能看出事项与动作/状态，非空泛口号
- [ ] 开头能让读者抓住核心判断或拟决定事项（文种需要时）
- [ ] 章节服务于读者决策或执行，无凑结构空章

## 事实与口径

- [ ] 事实 / 计划 / 建议 / 待核实已分开表述
- [ ] 阶段（规划、采购、实施、验收、运行）未混写
- [ ] 经费口径（估算、概算、报价、批复）未混用
- [ ] 数字带单位、范围、统计期及必要限定词
- [ ] 缺口已标【待确认】，未用润色补事实

## 行动与语气

- [ ] 需他方行动处写清事项、责任、时限（或标明拟定/待确认）
- [ ] 成效与评价未超出证据
- [ ] 语气偏企业材料：克制、可核对；少政府动员腔与排比堆砌
- [ ] 旧模板专名、地名、规模未混入；对标已标注边界

## 载体

- [ ] 简报/PPT/发言稿与正文在结论、状态、数字、诉求上一致
- [ ] 压缩未删掉关键风险、前提或协调诉求
